# バレーボール班編成ツール

Googleスプレッドシートから出力したCSVを読み込み、LINEの名前で参加者を指定して班を構成するローカルWebアプリです。

使用技術、ライブラリ、システム構成図、データベース構成、処理フローは[技術構成・システム設計](docs/TECHNICAL_OVERVIEW.md)にまとめています。

## 主な機能

- LINEの名前を1行に1人ずつ入力して会員情報を参照
- 1チームの人数、またはチーム数を指定
- 経験年数、学部、回生、男女比、過去の組み合わせを0～5の重みで調整
- 構成結果をテキストでコピー
- 確定した構成だけをSQLiteへ保存し、次回の組み合わせ判定に利用
- CSV読み込み・書き出し、会員情報の手入力
- 白と黒だけのレスポンシブ画面
- APIを使わず端末内で計算

## Windowsでの起動

1. Python 3.11以上をインストールします。
2. `start.bat`をダブルクリックします。
3. 初回だけ必要なパッケージがインストールされ、ブラウザで `http://127.0.0.1:5000` が開きます。
4. 終了するときは黒い画面を閉じます。

コマンドで起動する場合：

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python run.py
```

## 最初の使い方

1. 左上メニューから「会員リスト」を開きます。
2. GoogleスプレッドシートをCSV形式でダウンロードし、CSV読み込み欄から選択します。
3. トップ画面へ戻り、参加者のLINE名を1行ずつ入力します。
4. 分け方と優先順位を選び「チームを構成する」を押します。
5. 結果がよければ「チームを決定して履歴に保存する」を押します。

`data/sample_members.csv`で動作を試せます。サンプルは架空のデータです。

## 対応するCSV列

必須：

- `LINEの名前`（`LINE の名前`、`LINE名`なども可）

任意：

- `名前`
- `学部`
- `学籍番号`
- `回生`
- `バレーボール経験`
- `出身地(都道府県)`
- `誕生日`
- `性別`
- `役職`

現在のGoogleフォームには性別質問がないため、男女比を利用する場合はCSVに性別列を追加するか、「会員インタビューフォーム」画面から登録してください。名前から性別を推測することはありません。

## 編成ロジック

複数の初期構成を作り、チーム間で会員を入れ替えながら以下のペナルティが小さくなる構成を探索します。

- チームごとの平均経験年数の差
- 同じ学部・回生が同じチームに集まる割合
- 男女比と各チームへの分布差
- 過去に同じチームだった回数

優先順位を0にするとその項目を計算から外し、5にすると強く優先します。条件によって全項目を完全に満たせない場合は、指定した重みをもとに全体のバランスがよい案を返します。

## データとプライバシー

- 会員情報と履歴は `instance/team_builder.sqlite3` にだけ保存されます。
- 通常の班編成ではネットワーク通信やAI APIを使用しません。
- APIキー画面で入力したキーはPythonプロセスのメモリだけに置き、サーバー終了時に消えます。現バージョンの班編成では使用しません。
- `instance`フォルダを削除すると、会員リストと履歴も削除されます。

公開リポジトリへ実際の会員CSV、`instance`フォルダ、`.env`、APIキーをコミットしないでください。これらは`.gitignore`で除外していますが、公開前に`git status`で必ず確認してください。

## Googleフォームへのリンク

既存のGoogleフォームを会員インタビューフォーム画面から開きたい場合は、起動前に環境変数を設定します。

```powershell
$env:INTERVIEW_FORM_URL = "https://docs.google.com/forms/..."
python run.py
```
